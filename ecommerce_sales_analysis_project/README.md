
# E-Commerce Sales Analysis Dashboard

## Project Overview
This project analyzes an e-commerce sales dataset to uncover business insights and build an interactive dashboard.

## Tools Used
- Python (Pandas)
- Power BI
- Excel

## Project Steps
1. Data Cleaning using Python
2. Exploratory Data Analysis
3. Business Insight Generation
4. Power BI Dashboard Creation

## Key Insights (Example)
- Identify highest sales region
- Analyze profit by product category
- Study monthly sales trends
- Evaluate discount impact on profitability

## How to Use
1. Open the notebook in Jupyter or Google Colab
2. Run the analysis
3. Import `cleaned_superstore.csv` into Power BI
4. Create dashboard visuals

## Dashboard Ideas
- Total Sales KPI
- Profit by Category
- Sales by Region
- Monthly Sales Trend
- Discount vs Profit
